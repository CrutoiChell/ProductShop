### 🛍️ Fullstack Интернет-Магазин
**React + TypeScript + Express + PostgreSQL**  
Профессиональное решение с каталогом, корзиной и системой аутентификации

---

#### ✨ Основные особенности
- **Полный цикл покупок**: Просмотр товаров, добавление в корзину, оформление заказа
- **Современные технологии**: React 18, Express.js, PostgreSQL
- **Эффективный data-fetching**: RTK Query для работы с API
- **Прямой доступ к БД**: Нативный драйвер `pg` без ORM
- **TypeScript**: Типизация на фронтенде и бэкенде

---

#### ⚙️ Технологический стек
| Клиент | Сервер |
|---|---|
| React 18 | Express.js |
| TypeScript | Node.js 18+ |
| Redux Toolkit + RTK Query | JWT-аутентификация |
| React Router 6 | Драйвер pg |
| CSS Modules | Ручная валидация |
| Адаптивная вёрстка | CORS middleware |

---

#### 🚀 Функциональные модули
- **Каталог товаров**  
  Фильтрация, сортировка, пагинация, поиск
- **Корзина покупок**  
  Редактирование количества, расчёт стоимости
- **Личный кабинет**  
  История заказов, обновление профиля
- **Система аутентификации**  
  Регистрация, вход, защита роутов
- **Администрирование**  
  Управление товарами и заказами

---

#### 🔒 Безопасность
- Двухтокенная JWT-авторизация (access/refresh)
- Хеширование паролей с bcryptjs
- Проверка прав доступа на защищённых роутах
- Валидация всех входящих данных

---

#### 🏆 Ключевые возможности
- REST API для каталога, корзины, заказов и администрирования
- Создание адаптивного UI с продуманным UX
- Работа с PostgreSQL через нативный драйвер pg
- Интеграция системы оплаты в тестовом режиме

---

**Проект собран с нуля как fullstack-пример интернет-магазина.**  
Все компоненты написаны на TypeScript.
